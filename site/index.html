    Как учить, чтобы сдать

    Главное правилоНа экзамене нельзя ИИ, чаты, GitHub. Интернет — 15 минут. Значит, всё делаешь руками по памяти. Читать мало: нужно повторять на компьютере, пока не получится без подсказки.

    Как работать с каждым шагом

    1. Прочитай шаг на телефоне.
    2. Сделай на компьютере, подглядывая.
    3. Пройди проверку по этому шагу (кнопка «Проверка», выбери тему).
    4. Сделай снова без подсказки на следующий день. Не получилось — посмотри только то место, где застрял.

    Как учить код

    • Не учи весь файл. Учи по этапам (шаг 6): каждый этап — 20–60 строк.
    • Каждый день открывай пустой файл и пиши от начала до этапа, который учишь.
    • Запомни смысл куска («проверить пусто → ошибка → найти в базе»), а не буквы.
    • Ошибся — читай сообщение Python (шаг 7). Это тоже тренировка.

    Excel → CSV UTF-8

    Результат5 файлов CSV: users.csv, pvz.csv, tovar.csv, zakaz.csv, zakaz_tovar.csv. Русские буквы читаются, заголовки латиницей, ошибки исправлены.

    Зачем вообще чистить: DB Browser загружает CSV как есть. Любая грязь (пробел в конце, пустая строка, дата в разном виде) потом ломает связи между таблицами.

    1.1 Общие правила для каждого файла

    1. Открой файл (.xls или .xlsx) в Excel. Если сверху жёлтая полоса — «Разрешить редактирование».
    2. Заголовки латиницей, маленькими буквами, без пробелов: art, name… Так SQL пишется без кавычек.
    3. Удали пустые столбцы и строки справа и снизу (выдели → правой кнопкой → «Удалить»).
    4. Убери лишние пробелы. Пробел в конце глазом не видно. Формула =СЖПРОБЕЛЫ(A2) в соседнем столбце убирает лишние пробелы; потом скопируй → «Вставить значения» поверх старого столбца.
    5. Даты — формат ГГГГ-ММ-ДД: выдели столбец → правой кнопкой «Формат ячеек» → «(все форматы)» → впиши ГГГГ-ММ-ДД.
    6. Ищи ошибки в данных (их кладут специально): несуществующая дата, опечатка в имени, дата заказа позже даты доставки. Исправь и запиши, что исправил, — потом в отчёт.
    7. Сохрани: «Файл» → «Сохранить как» → тип CSV UTF-8 (разделитель — запятая). На вопрос про несколько листов — сохраняй каждый лист отдельно.
    Только CSV UTF-8Обычный «CSV (разделители — запятые)» сохраняет в старой кодировке. В базе вместо русских букв будут знаки вопроса.

    1.2 Что менять в каждом файле

    1. Создай новый лист, заголовки: zak_id, art, quant.
    2. Для каждого заказа запиши его товары по строкам:

    РезультатФайл shop.db с 10 таблицами и данными + скрипт shop_script.sql.

    2.1 Что надо понимать (5 минут)

    • Таблица — как лист Excel. Строка — запись (один товар), столбец — поле (цена).
    • Первичный ключ (PRIMARY KEY) — номер строки id. Не повторяется, ставится сам (AUTOINCREMENT).
    • Внешний ключ (REFERENCES) — поле, где лежит id из другой таблицы. В товаре хранится не «Kari», а номер поставщика.
    • 3-я нормальная форма — всё, что повторяется (роль, поставщик, производитель, категория, статус, пункт выдачи), выносим в отдельную маленькую таблицу-справочник.
    • Многие ко многим — в заказе много товаров, товар во многих заказах. Нужна таблица-связка zakaz_tovar.

    Наша база: 10 таблиц, 9 связей. Подчёркнуто — первичный ключ, зелёным — внешний ключ. Прокрути схему вбок.

-- Соответствует ER-диаграмме: 10 таблиц, 9 связей.
PRAGMA foreign_keys = ON;

-- ===== Справочники =====

CREATE TABLE role (
    id   INTEGER PRIMARY KEY AUTOINCREMENT,
    role TEXT NOT NULL UNIQUE              -- Администратор / Менеджер / Авторизированный клиент
);

CREATE TABLE status (
    id     INTEGER PRIMARY KEY AUTOINCREMENT,
    status TEXT NOT NULL UNIQUE            -- Новый / Завершен
);

CREATE TABLE pvz (
    id   INTEGER PRIMARY KEY AUTOINCREMENT,
    addr TEXT NOT NULL                     -- адрес пункта выдачи
);

CREATE TABLE suppl (
    id    INTEGER PRIMARY KEY AUTOINCREMENT,
    suppl TEXT NOT NULL UNIQUE             -- поставщик
);

CREATE TABLE manuf (
    id    INTEGER PRIMARY KEY AUTOINCREMENT,
    manuf TEXT NOT NULL UNIQUE             -- производитель
);

CREATE TABLE cat (
    id  INTEGER PRIMARY KEY AUTOINCREMENT,
    cat TEXT NOT NULL UNIQUE               -- категория товара
);

-- ===== Основные таблицы =====

CREATE TABLE users (
    id      INTEGER PRIMARY KEY AUTOINCREMENT,
    role_id INTEGER NOT NULL REFERENCES role(id),
    fio     TEXT NOT NULL,
    login   TEXT NOT NULL UNIQUE,
    pass    TEXT NOT NULL
);

CREATE TABLE tovar (
    id       INTEGER PRIMARY KEY AUTOINCREMENT,
    art      TEXT NOT NULL UNIQUE,          -- артикул
    name     TEXT NOT NULL,                 -- наименование
    unit     TEXT NOT NULL DEFAULT 'шт.',   -- единица измерения
    price    REAL NOT NULL CHECK (price >= 0),
    suppl    INTEGER NOT NULL REFERENCES suppl(id),
    manuf    INTEGER NOT NULL REFERENCES manuf(id),
    cat      INTEGER NOT NULL REFERENCES cat(id),
    discount INTEGER NOT NULL DEFAULT 0 CHECK (discount BETWEEN 0 AND 100),  -- скидка, %
    quant    INTEGER NOT NULL DEFAULT 0 CHECK (quant >= 0),                  -- кол-во на складе
    descr    TEXT,                          -- описание
    photo    TEXT                           -- имя файла фото (может быть пустым)
);

CREATE TABLE zakaz (
    id        INTEGER PRIMARY KEY AUTOINCREMENT,
    zak_date  TEXT NOT NULL,                -- дата заказа, ГГГГ-ММ-ДД
    dost_date TEXT NOT NULL,                -- дата доставки, ГГГГ-ММ-ДД
    pvz_id    INTEGER NOT NULL REFERENCES pvz(id),
    user_id   INTEGER NOT NULL REFERENCES users(id),
    code      INTEGER NOT NULL,             -- код для получения
    status_id INTEGER NOT NULL REFERENCES status(id)
);

-- Состав заказа (связь «многие ко многим» между zakaz и tovar)
CREATE TABLE zakaz_tovar (
    zak_id   INTEGER NOT NULL REFERENCES zakaz(id) ON DELETE CASCADE,
    tovar_id INTEGER NOT NULL REFERENCES tovar(id),
    quant    INTEGER NOT NULL CHECK (quant > 0),
    PRIMARY KEY (zak_id, tovar_id)
);

    PRIMARY KEY AUTOINCREMENTпервичный ключ, номер ставится сам
    NOT NULLполе обязательно
    UNIQUEбез повторов
    REFERENCES role(id)внешний ключ на таблицу role
    CHECK (price >= 0)проверка значения

    2.4 Перенести данные

    «Выполнить SQL» → вставь → ▶ → «Записать изменения». Порядок важен: сначала справочники, потом то, что на них ссылается.

    -- Перенос данных из импортированных CSV-таблиц (imp_*) в таблицы базы.
-- Порядок: сначала справочники, потом таблицы, которые на них ссылаются.
-- Перед запуском: выполнен schema.sql и импортированы CSV:
--   imp_users       (role, fio, login, pass)
--   imp_pvz         (addr)
--   imp_tovar       (art, name, unit, price, suppl, manuf, cat, discount, quant, descr, photo)
--   imp_zakaz       (num, zak_date, dost_date, pvz, fio, code, status)
--   imp_zakaz_tovar (zak_id, art, quant)

INSERT INTO role (role) SELECT DISTINCT TRIM(role) FROM imp_users;

INSERT INTO users (role_id, fio, login, pass)
SELECT role.id, TRIM(i.fio), TRIM(i.login), i.pass
FROM imp_users i
JOIN role ON role.role = TRIM(i.role);

INSERT INTO pvz (addr) SELECT TRIM(addr) FROM imp_pvz ORDER BY rowid;

INSERT INTO suppl (suppl) SELECT DISTINCT TRIM(suppl) FROM imp_tovar;
INSERT INTO manuf (manuf) SELECT DISTINCT TRIM(manuf) FROM imp_tovar;
INSERT INTO cat (cat)     SELECT DISTINCT TRIM(cat)   FROM imp_tovar;

INSERT INTO tovar (art, name, unit, price, suppl, manuf, cat, discount, quant, descr, photo)
SELECT TRIM(i.art), TRIM(i.name), TRIM(i.unit), i.price, suppl.id, manuf.id, cat.id,
       i.discount, i.quant, TRIM(i.descr), NULLIF(TRIM(i.photo), '')
FROM imp_tovar i
JOIN suppl ON suppl.suppl = TRIM(i.suppl)
JOIN manuf ON manuf.manuf = TRIM(i.manuf)
JOIN cat   ON cat.cat     = TRIM(i.cat);

INSERT INTO status (status) SELECT DISTINCT TRIM(status) FROM imp_zakaz;

INSERT INTO zakaz (id, zak_date, dost_date, pvz_id, user_id, code, status_id)
SELECT i.num, i.zak_date, i.dost_date, i.pvz, users.id, i.code, status.id
FROM imp_zakaz i
JOIN users  ON users.fio = TRIM(i.fio)
JOIN status ON status.status = TRIM(i.status);

INSERT INTO zakaz_tovar (zak_id, tovar_id, quant)
SELECT i.zak_id, tovar.id, i.quant
FROM imp_zakaz_tovar i
JOIN tovar ON tovar.art = TRIM(i.art);

-- Проверка: числа должны совпасть с количеством строк в Excel
SELECT 'users', COUNT(*) FROM users UNION ALL
SELECT 'pvz', COUNT(*) FROM pvz UNION ALL
SELECT 'tovar', COUNT(*) FROM tovar UNION ALL
SELECT 'zakaz', COUNT(*) FROM zakaz UNION ALL
SELECT 'zakaz_tovar', COUNT(*) FROM zakaz_tovar;

DROP TABLE imp_users;
DROP TABLE imp_pvz;
DROP TABLE imp_tovar;
DROP TABLE imp_zakaz;

    Как это читать: INSERT INTO suppl (suppl) SELECT DISTINCT TRIM(suppl) FROM imp_tovar — «возьми всех поставщиков из сырого Excel без повторов и положи в справочник». JOIN suppl ON suppl.suppl = i.suppl — «найди номер поставщика по названию».

    DbVisualizer: ER-схема

    Результатer_diagram.pdf: таблицы, поля, ключи, стрелки-связи.

    DbVisualizer сам рисует схему по базе. Стрелки берутся из внешних ключей (REFERENCES). Нет ключей — нет стрелок.

    3.1 Подключить базу

    1. В DB Browser нажми «Записать изменения» (иначе DbVisualizer увидит пустую базу).
    2. DbVisualizer → слева Databases → + → Create Database Connection → SQLite.
    3. Имя, например Обувь. Поле файла базы → выбери shop.db → Connect.
    ДрайверПервый раз DbVisualizer качает драйвер SQLite из интернета. В подготовительный день проверь, что на экзаменационном компьютере подключение к SQLite уже работает.

    3.2 Открыть схему

    1. Слева: Обувь → Schema → Tables. Двойной щелчок по Tables.
    2. Справа вкладка References.

    3.3 Настройки как на паре

    Layout: Hierarchical — над схемой.
    Display Options: All Tables — справа.
    Node Content: Columns — видно поля.
    Show Data Type — типы рядом с полями (по желанию).
    Links to Columns — стрелка от конкретного поля.

    Внизу справа: Tables: 10, References: 9. Это проверка, что всё верно.

    3.4 Сохранить в PDF

    1. Кнопка печати на панели над схемой → принтер Microsoft Print to PDF → er_diagram.pdf.
    2. Не вышло — скриншот Win+Shift+S → вставить в Word → «Сохранить как» → PDF.

    3.5 Если не так

    ВидишьДелай
    Таблиц нет / пустыеDB Browser: «Записать изменения». DbVisualizer: Refresh (F5).
    Стрелок нетНет REFERENCES в скрипте таблиц. Пересоздай базу.
    Есть таблицы imp_…Не выполнил DROP TABLE imp_….

    def filter_products(self, products):
        supplier = self.supplier_box.get()
        if supplier != ALL_SUPPLIERS:
            products = [product for product in products if product["suppl"] == supplier]

        words = self.search_var.get().lower().split()
        if words:
            text_fields = ("art", "name", "cat", "descr", "manuf", "suppl", "unit")
            found = []
            for product in products:
                text = " ".join(str(product[field] or "") for field in text_fields).lower()
                if all(word in text for word in words):
                    found.append(product)
            products = found

        if self.sort_box.get() == SORT_ASC:
            products = sorted(products, key=lambda product: product["quant"])
        elif self.sort_box.get() == SORT_DESC:
            products = sorted(products, key=lambda product: product["quant"], reverse=True)
        return products

def connect():
    conn = sqlite3.connect(DB_PATH)
    conn.row_factory = sqlite3.Row

    with connect() as conn:

def execute(sql, params=()):
    with connect() as conn:
        return conn.execute(sql, params).lastrowid

def make_scroll_area(parent):
    """Прокручиваемая область: Frame внутри Canvas, потому что сам Frame не прокручивается."""
    canvas = tk.Canvas(parent, bg=COLOR_BG, highlightthickness=0)
    scrollbar = tk.Scrollbar(parent, orient="vertical", command=canvas.yview)
    inner = tk.Frame(canvas, bg=COLOR_BG)
    inner.bind("<Configure>", lambda event: canvas.configure(scrollregion=canvas.bbox("all")))
    window_id = canvas.create_window((0, 0), window=inner, anchor="nw")
    canvas.bind("<Configure>", lambda event: canvas.itemconfigure(window_id, width=event.width))
    canvas.configure(yscrollcommand=scrollbar.set)
    canvas.bind_all("<MouseWheel>", lambda event: canvas.yview_scroll(int(-event.delta / 120), "units"))
    scrollbar.pack(side="right", fill="y")
    canvas.pack(side="left", fill="both", expand=True)
    return inner

    def filter_products(self, products):
        supplier = self.supplier_box.get()
        if supplier != ALL_SUPPLIERS:
            products = [product for product in products if product["suppl"] == supplier]

        words = self.search_var.get().lower().split()
        if words:
            text_fields = ("art", "name", "cat", "descr", "manuf", "suppl", "unit")
            found = []
            for product in products:
                text = " ".join(str(product[field] or "") for field in text_fields).lower()
                if all(word in text for word in words):
                    found.append(product)
            products = found

        if self.sort_box.get() == SORT_ASC:
            products = sorted(products, key=lambda product: product["quant"])
        elif self.sort_box.get() == SORT_DESC:
            products = sorted(products, key=lambda product: product["quant"], reverse=True)
        return products

def order_items_text(order_id):

    def read_form(self):
        art = self.art_entry.get().strip()
        name = self.name_entry.get().strip()
        if not art or not name:
            raise ValueError("Заполните поля «Артикул» и «Наименование».")
        for box, field in ((self.category_box, "категорию"), (self.manuf_box, "производителя"),
                           (self.suppl_box, "поставщика")):
            if not box.get():
                raise ValueError(f"Выберите {field} из выпадающего списка.")
        try:
            price = round(float(self.price_entry.get().replace(",", ".")), 2)
        except ValueError:
            raise ValueError("Цена должна быть числом, например 1999.99.") from None
        if price < 0:
            raise ValueError("Цена не может быть отрицательной.")
        try:
            quant = int(self.quant_entry.get())
            discount = int(self.discount_entry.get())
        except ValueError:
            raise ValueError("Количество и скидка должны быть целыми числами, например 5.") from None
        if quant < 0:
            raise ValueError("Количество на складе не может быть отрицательным.")
        if not 0 <= discount <= 100:
            raise ValueError("Скидка должна быть от 0 до 100 %.")
        return {
            "art": art, "name": name, "unit": self.unit_entry.get().strip() or "шт.",
            "price": price, "suppl": self.suppliers[self.suppl_box.get()],
            "manuf": self.manufacturers[self.manuf_box.get()], "cat": self.categories[self.category_box.get()],
            "discount": discount, "quant": quant, "descr": self.descr_text.get("1.0", "end").strip(),
            "photo": self.value("photo", None),
        }

    def save_new_photo(self, art):
        image = Image.open(self.new_photo_path)
        image.thumbnail((300, 200))
        file_name = f"{art}_{datetime.now():%Y%m%d%H%M%S}.jpg"
        image.convert("RGB").save(os.path.join(RES_DIR, file_name), "JPEG")
        return file_name

    def delete_photo_file(self, file_name):
        path = os.path.join(RES_DIR, file_name or "")
        if file_name and file_name != PLACEHOLDER and os.path.exists(path):
            os.remove(path)

    def save(self):
        try:
            data = self.read_form()
        except ValueError as error:
            self.error("Ошибка ввода", str(error))
            return

        old_photo = data["photo"]
        try:
            if self.new_photo_path:
                data["photo"] = self.save_new_photo(data["art"])
            columns = ("art", "name", "unit", "price", "suppl", "manuf", "cat", "discount", "quant", "descr", "photo")
            values = [data[column] for column in columns]
            if self.product_id:
                assignments = ", ".join(f"{column} = ?" for column in columns)
                execute(f"UPDATE tovar SET {assignments} WHERE id = ?", values + [self.product_id])
            else:
                execute(f"INSERT INTO tovar ({', '.join(columns)}) VALUES ({', '.join('?' * len(columns))})", values)
        except sqlite3.IntegrityError:
            self.error("Ошибка сохранения", "Товар с таким артикулом уже существует. Укажите другой артикул.")
            return
        except (sqlite3.Error, OSError) as error:
            self.error("Ошибка сохранения", f"Не удалось сохранить товар: {error}")
            return

        if self.new_photo_path:
            self.delete_photo_file(old_photo)
        messagebox.showinfo("Сохранено", "Данные товара сохранены.", parent=self)
        self.destroy()
        self.app.refresh_products()

    def delete(self):
        orders = query("SELECT COUNT(*) AS n FROM zakaz_tovar WHERE tovar_id = ?", (self.product_id,))[0]["n"]
        if orders:
            self.error("Удаление невозможно",
                       f"Этот товар есть в заказах (заказов: {orders}). Товар, который присутствует в заказе, удалить нельзя.")

        if not messagebox.askyesno("Подтверждение удаления",

                                   "Это действие нельзя отменить.", icon="warning", parent=self):
            return
        execute("DELETE FROM tovar WHERE id = ?", (self.product_id,))
        self.delete_photo_file(self.product["photo"])
        messagebox.showinfo("Удалено", "Товар удалён.", parent=self)
        self.destroy()
        self.app.refresh_products()


class OrderForm(BaseForm):
    def __init__(self, app, order_id):
        super().__init__(app, "Редактирование заказа" if order_id else "Добавление заказа")
        self.order_id = order_id
        order = query("SELECT * FROM zakaz WHERE id = ?", (order_id,))[0] if order_id else None

        self.statuses = {row["status"]: row["id"] for row in query("SELECT id, status FROM status")}
        self.addresses = {row["addr"]: row["id"] for row in query("SELECT id, addr FROM pvz ORDER BY id")}
        self.clients = {row["fio"]: row["id"] for row in query("SELECT id, fio FROM users ORDER BY fio")}

        def name_of(names, item_id):
            return next((name for name, value in names.items() if value == item_id), "")

        if order_id:
            id_entry = self.entry("Номер заказа", order_id)
            id_entry.configure(state="readonly")
        self.items_entry = self.entry("Артикул (артикул, кол-во, ...)",
                                      order_items_text(order_id) if order_id else "")
        self.status_box = self.combobox("Статус заказа", list(self.statuses),
                                        name_of(self.statuses, order["status_id"]) if order else "")
        self.address_box = self.combobox("Адрес пункта выдачи", list(self.addresses),
                                         name_of(self.addresses, order["pvz_id"]) if order else "")
        self.client_box = self.combobox("Клиент", list(self.clients),
                                        name_of(self.clients, order["user_id"]) if order else "")
        self.zak_date_entry = self.entry("Дата заказа (ГГГГ-ММ-ДД)", order["zak_date"] if order else "")
        self.dost_date_entry = self.entry("Дата выдачи (ГГГГ-ММ-ДД)", order["dost_date"] if order else "")

        self.add_buttons(self.save, self.delete if order_id else None)

    def read_items(self):
        parts = [part.strip() for part in self.items_entry.get().split(",") if part.strip()]
        if not parts or len(parts) % 2 != 0:
            raise ValueError("Укажите товары парами «артикул, количество», например: А112Т4, 2, F635R4, 1")
        items = {}
        for art, quant_text in zip(parts[::2], parts[1::2]):
            rows = query("SELECT id FROM tovar WHERE art = ?", (art,))
            if not rows:
                raise ValueError(f"Товар с артикулом «{art}» не найден. Проверьте артикул.")
            if not quant_text.isdigit() or int(quant_text) == 0:
                raise ValueError(f"Количество для «{art}» должно быть целым числом больше 0.")
            if rows[0]["id"] in items:
                raise ValueError(f"Артикул «{art}» указан дважды. Объедините количество в одну пару.")
            items[rows[0]["id"]] = int(quant_text)
        return items

    def read_date(self, entry, field):
        try:
            return datetime.strptime(entry.get().strip(), "%Y-%m-%d").date()
        except ValueError:
            raise ValueError(f"{field}: введите существующую дату в формате ГГГГ-ММ-ДД, например 2025-04-20.") from None

    def save(self):
        try:
            items = self.read_items()
            for box, field in ((self.status_box, "статус"), (self.address_box, "адрес пункта выдачи"),
                               (self.client_box, "клиента")):
                if not box.get():
                    raise ValueError(f"Выберите {field} из выпадающего списка.")
            zak_date = self.read_date(self.zak_date_entry, "Дата заказа")
            dost_date = self.read_date(self.dost_date_entry, "Дата выдачи")
            if dost_date < zak_date:
                raise ValueError("Дата выдачи не может быть раньше даты заказа.")
        except ValueError as error:
            self.error("Ошибка ввода", str(error))
            return

        values = (zak_date.isoformat(), dost_date.isoformat(), self.addresses[self.address_box.get()],
                  self.clients[self.client_box.get()], self.statuses[self.status_box.get()])
        try:
            # Заказ и его состав сохраняются в одной транзакции: либо всё, либо ничего
            with connect() as conn:
                if self.order_id:
                    order_id = self.order_id
                    conn.execute("UPDATE zakaz SET zak_date = ?, dost_date = ?, pvz_id = ?, user_id = ?, "
                                 "status_id = ? WHERE id = ?", values + (order_id,))
                    conn.execute("DELETE FROM zakaz_tovar WHERE zak_id = ?", (order_id,))
                else:
                    code = conn.execute("SELECT COALESCE(MAX(code), 900) + 1 FROM zakaz").fetchone()[0]
                    order_id = conn.execute("INSERT INTO zakaz (zak_date, dost_date, pvz_id, user_id, status_id, code) "
                                            "VALUES (?, ?, ?, ?, ?, ?)", values + (code,)).lastrowid
                conn.executemany("INSERT INTO zakaz_tovar (zak_id, tovar_id, quant) VALUES (?, ?, ?)",
                                 [(order_id, tovar_id, quant) for tovar_id, quant in items.items()])
        except sqlite3.Error as error:
            self.error("Ошибка сохранения", f"Не удалось сохранить заказ: {error}")
            return

        messagebox.showinfo("Сохранено", "Заказ сохранён.", parent=self)
        self.destroy()
        self.app.refresh_orders()

    def delete(self):
        if not messagebox.askyesno("Подтверждение удаления",
                                   f"Удалить заказ № {self.order_id}?\nЭто действие нельзя отменить.",
                                   icon="warning", parent=self):
            return
        # Состав заказа удалится сам: в zakaz_tovar стоит ON DELETE CASCADE
        execute("DELETE FROM zakaz WHERE id = ?", (self.order_id,))
        messagebox.showinfo("Удалено", "Заказ удалён.", parent=self)
        self.destroy()
        self.app.refresh_orders()

    -- Перенос данных из импортированных CSV-таблиц (imp_*) в таблицы базы.
-- Порядок: сначала справочники, потом таблицы, которые на них ссылаются.
-- Перед запуском: выполнен schema.sql и импортированы CSV:
--   imp_users       (role, fio, login, pass)
--   imp_pvz         (addr)
--   imp_tovar       (art, name, unit, price, suppl, manuf, cat, discount, quant, descr, photo)
--   imp_zakaz       (num, zak_date, dost_date, pvz, fio, code, status)
--   imp_zakaz_tovar (zak_id, art, quant)

INSERT INTO role (role) SELECT DISTINCT TRIM(role) FROM imp_users;

INSERT INTO users (role_id, fio, login, pass)
SELECT role.id, TRIM(i.fio), TRIM(i.login), i.pass
FROM imp_users i
JOIN role ON role.role = TRIM(i.role);

INSERT INTO pvz (addr) SELECT TRIM(addr) FROM imp_pvz ORDER BY rowid;

INSERT INTO suppl (suppl) SELECT DISTINCT TRIM(suppl) FROM imp_tovar;
INSERT INTO manuf (manuf) SELECT DISTINCT TRIM(manuf) FROM imp_tovar;
INSERT INTO cat (cat)     SELECT DISTINCT TRIM(cat)   FROM imp_tovar;

INSERT INTO tovar (art, name, unit, price, suppl, manuf, cat, discount, quant, descr, photo)
SELECT TRIM(i.art), TRIM(i.name), TRIM(i.unit), i.price, suppl.id, manuf.id, cat.id,
       i.discount, i.quant, TRIM(i.descr), NULLIF(TRIM(i.photo), '')
FROM imp_tovar i
JOIN suppl ON suppl.suppl = TRIM(i.suppl)
JOIN manuf ON manuf.manuf = TRIM(i.manuf)
JOIN cat   ON cat.cat     = TRIM(i.cat);

INSERT INTO status (status) SELECT DISTINCT TRIM(status) FROM imp_zakaz;

INSERT INTO zakaz (id, zak_date, dost_date, pvz_id, user_id, code, status_id)

JOIN users  ON users.fio = TRIM(i.fio)
JOIN status ON status.status = TRIM(i.status);

FROM imp_zakaz_tovar i
