# Подготовка к демоэкзамену 09.02.07

Учебный проект к демоэкзамену по специальности «Информационные системы и программирование»
(КОД 09.02.07-2-2026): база данных и приложение для магазина обуви на Python + tkinter + SQLite.

## Что здесь

| Файл / папка | Что это |
|---|---|
| `schema.sql` | Скрипт базы данных: таблицы, первичные и внешние ключи (модуль 1) |
| `migrate.sql` | Перенос данных из импортированных CSV (`imp_*`) в таблицы — способ для DB Browser |
| `create_db.py` | Создаёт `shop.db` из `schema.sql` и xlsx-файлов из `import` одной командой |
| `shop.db` | Готовая база SQLite (обувь, из `import`) |
| `shop_import2.db` | База второго варианта (из `import2`) для тренировки |
| `er_diagram.svg` | ER-диаграмма базы: 10 таблиц, 9 связей |
| `shop_app.py` | Приложение: вход, роли, товары с поиском/фильтром/сортировкой, форма товара, заказы |
| `import/` | Данные варианта «обувь» (xlsx, фото, иконка, заглушка `picture.png`) |
| `import2/` | Данные второго варианта для тренировки |
| `ПОДГОТОВКА.md` | Разбор экзамена и чек-листы по модулям |
| `course.html` | Исходник учебного курса (13 уроков, карточки) |
| `build_site.py` | Собирает курс: `site/index.html` для Vercel и `учебник.html` |
| `site/` | Учебный сайт для телефона (деплоится на Vercel) |

## Запуск

Нужны Python 3 и Pillow (`pip install pillow`).

```bash
python create_db.py
python shop_app.py
```

Собрать базу из второго варианта: `python create_db.py import2`.

## Учебный сайт

После правки `course.html` или кода пересобрать сайт (код в курс подставляется из настоящих файлов):

```bash
python build_site.py
```

Vercel берёт готовые файлы из папки `site/` (настроено в `vercel.json`), сборка не нужна.
