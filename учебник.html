Как устроена база

Таблица похожа на лист Excel: строки — записи, столбцы — поля. У каждой строки есть номер id, это первичный ключ: он никогда не повторяется.

Внешний ключ — поле, где хранится id из другой таблицы. Например, в users.role_id записано 2, а не слово «Менеджер». На ER-диаграмме это стрелка.

3-я нормальная форма простыми словами: один факт хранится в одном месте. Слово «Kari» записано один раз в таблице suppl, а у товаров только его номер.

zakaz_tovar нужна потому, что в одном заказе много товаров, а один товар бывает во многих заказах. Это связь «многие ко многим».

SQL-шпаргалка

Создать таблицу

CREATE TABLE users (
    id      INTEGER PRIMARY KEY AUTOINCREMENT,
    role_id INTEGER NOT NULL REFERENCES role(id),
    fio     TEXT NOT NULL,
    login   TEXT NOT NULL UNIQUE,
    pass    TEXT NOT NULL
);

NOT NULL — поле обязательно. UNIQUE — без повторов. AUTOINCREMENT — номер ставится сам.

Добавить, изменить, удалить

INSERT INTO role (role) VALUES ('Менеджер');
UPDATE tovar SET quant = 10 WHERE id = 3;
DELETE FROM tovar WHERE id = 3;
Опасно: UPDATE и DELETE без WHERE меняют или стирают все строки таблицы.

Выбрать с соединением таблиц

SELECT users.fio, role.role
FROM users
JOIN role ON role.id = users.role_id
WHERE users.login = ? AND users.pass = ?;

JOIN ... ON склеивает строки двух таблиц, где номер совпадает. Так вместо role_id = 2 получаем слово «Менеджер».

Поиск и сортировка

SELECT * FROM tovar
WHERE name LIKE '%бот%'
ORDER BY quant DESC;

LIKE '%бот%' — содержит «бот». ASC — по возрастанию, DESC — по убыванию.

Шаг 1: окно входа

Файл shop_app.py. Разбор по кускам: запоминай идею каждого куска, а не буквы.

1. Импорты

import sqlite3
import tkinter as tk
from tkinter import messagebox

from PIL import Image, ImageTk

sqlite3 — работа с базой. tkinter — окна и кнопки. messagebox — всплывающие сообщения. PIL (Pillow) — открыть jpg и изменить размер.

2. Одна функция для всех запросов

def query(sql, params=()):
    with sqlite3.connect(DB_PATH) as conn:
        return conn.execute(sql, params).fetchall()

Подключается к базе, выполняет запрос, возвращает список строк. Значения передаются через ?, а не вклеиваются в текст запроса: так защищаются от SQL-инъекций.

3. Класс окна

class ShopApp(tk.Tk):
    def __init__(self):
        super().__init__()
        self.geometry("1000x650")
        self.iconbitmap(f"{RES_DIR}/Icon.ico")
        self.logo = ImageTk.PhotoImage(Image.open(f"{RES_DIR}/Icon.png").resize((80, 80)))
        self.user_fio = None
        self.user_role = None
        self.show_login()

self — «память» программы. Всё, что должно жить между экранами (кто вошёл, логотип), хранится в self.что-то.

Ловушка: картинку обязательно сохранять в self.logo. Если положить её в обычную переменную, Python её удалит, и на экране будет пусто, без всякой ошибки.

4. Смена экранов

def clear_window(self):
    for widget in self.winfo_children():
        widget.destroy()

Окно одно. Чтобы показать новый экран, удаляем всё старое и рисуем новое. Каждый экран — своя функция: show_login(), show_products().

5. Проверка логина

def login(self):
    login = self.login_entry.get().strip()
    password = self.password_entry.get()
    if not login or not password:
        messagebox.showwarning("Не все поля заполнены", "Введите логин и пароль.")
        return

    rows = query(
        "SELECT users.fio, role.role FROM users "
        "JOIN role ON role.id = users.role_id "
        "WHERE users.login = ? AND users.pass = ?",
        (login, password),
    )
    if not rows:
        messagebox.showerror("Ошибка входа", "Неверный логин или пароль. ...")
        return

    self.user_fio, self.user_role = rows[0]
    self.show_products()

Три шага, которые нужно помнить наизусть:

  • поля пустые → showwarning и выход из функции;
  • запрос ничего не нашёл → showerror и выход;
  • нашёл → запомнить ФИО и роль в self, показать товары.

6. Шапка с ФИО и выходом

tk.Button(header, text="Выход", command=self.show_login).pack(side="right")
tk.Label(header, text=f"{self.user_fio} ({self.user_role})").pack(side="right")

side="right" прижимает к правому краю: так ФИО оказывается в правом верхнем углу, как требует задание. command= — какую функцию вызвать по нажатию (без скобок!).

Ловушки

Данные. В import есть дата 30.02.2025, пробел в конце «Новый », заказ 2022 года среди 2025-х, товары без фото. Эксперты проверяют, заметил ли ты.
Кодировка. CSV для импорта сохранять в UTF-8, иначе вместо русских букв будут знаки вопроса.
command=self.login() со скобками вызовет функцию сразу при запуске, а не по нажатию. Правильно: command=self.login.
Картинки в tkinter пропадают, если не сохранить ссылку в self.
Удаление товара из заказа запрещено: перед DELETE проверить, есть ли он в zakaz_tovar.
